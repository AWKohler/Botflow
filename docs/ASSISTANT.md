# Botflow Documentation Assistant

Botflow is a browser-based IDE that lets you build, run, and deploy full-stack web applications without installing anything locally. Each project runs in its own cloud sandbox — a real, isolated Linux environment with Node.js, a full filesystem, and a terminal — which the in-browser IDE drives over the network.

## Key concepts

- **Projects** — workspaces that contain your code, files, and settings
- **Editor** — Monaco-based code editor with syntax highlighting and autocomplete
- **AI Assistant** — generates and edits code using OpenAI and Anthropic models
- **Preview** — live preview of your app running in the sandbox
- **Deploy** — one-click publishing to a public URL

## Stack

Botflow supports web templates (Vite, Next.js) out of the box.
